Getting Started

Konfiguracja FenixExelent

Skonfiguruj bota FenixExelent na swoim serwerze Discord w kilku krokach. Możesz używać zarówno komend slash, jak i panelu WWW.

Dodaj bota Otwórz dashboard

⚠️ Wymagane uprawnienia

Bot powinien mieć uprawnienia administratora lub minimum: zarządzanie kanałami, rolami, wiadomościami, banowanie, wyrzucanie, timeout oraz wysyłanie wiadomości.

🚫 Zagrożenia, które blokujemy

FenixExelent monitoruje wiadomości, linki i akcje administracyjne, aby zatrzymać najczęstsze zagrożenia zanim wyrządzą szkody na serwerze.

🌐Scam linki i phishing
🧲IP loggery
🎁Fake Discord Nitro
🎮Fake Steam rewards
🪙Crypto giveaway scam
💬Spam i flood
🚨Masowe wejścia botów
🔒Nieautoryzowane tworzenie kanałów
🪝Nadużywanie webhooków
🧪Podejrzane domeny .xyz / .click / .top / .work
⚠️Niebezpieczne uprawnienia
📣Ping @everyone i @here

Szybka konfiguracja

1

Dodaj bota na serwer

Kliknij przycisk „Dodaj bota”, wybierz serwer i zaakceptuj uprawnienia.

https://fenixexelent.onrender.com/invite
2

Zarejestruj komendy slash

Uruchom komendę w PowerShellu w folderze projektu.

npm run deploy
3

Uruchom bota

Po starcie bot pokaże status online i link do dashboardu.

npm start
4

Wykonaj automatyczny setup

Na Discordzie wpisz komendę:

/setup

Najważniejsze komendy

/setup

Tworzy kanały statystyk, regulamin, weryfikację, logi i kategorię ticketów.

/dashboard

Wysyła link do panelu WWW.

/security

Pokazuje panel bezpieczeństwa z przyciskami.

/status

Pokazuje aktualny status modułów.

🛡️ AntiSpam

Chroni serwer przed spamem, floodem i szybkim wysyłaniem wiadomości.

/antispam on
/antispam off
/antispam set wiadomosci:5 czas:3 mute:10
/antispam log kanal:#logi

🚨 AntiRaid

Wykrywa masowe dołączenia i automatycznie reaguje kickiem, banem lub mutem.

/antiraid on
/antiraid set dolaczenia:10 czas:10 akcja:kick
/antiraid lockdown aktywny:true

🔒 Channel Guard

Blokuje nieautoryzowane tworzenie kanałów i zapisuje incydenty w logach.

/channelguard on
/channelguard whitelist rola:@Admin
/channelguard log kanal:#security-logi

✅ Weryfikacja

Użytkownik klika przycisk weryfikacji i automatycznie otrzymuje rolę.

/verification setup rola:@Zweryfikowany
/verification on
/verification panel

🎫 Tickety

Tworzy prywatne kanały pomocy dla użytkowników i supportu.

/ticket setup rola:@Support logi:#ticket-logi
/ticket on
/ticket panel

📋 Logi

Ustaw kanały logów, aby bot zapisywał akcje moderacyjne, antyspam, antyraid i tickety.

/modlog kanal:#mod-logi
/antispam log kanal:#antispam-logi
/antiraid log kanal:#antiraid-logi
