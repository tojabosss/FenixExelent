Instrukcja uruchomienia 3.2

Uruchom bota i panel WWW

Ta wersja ma jeden wspólny zestaw ustawień dla Discorda i dashboardu. Zmiana w panelu jest zapisywana w tej samej konfiguracji, z której korzysta bot.

Otwórz dashboard Zaproś bota
Ważne: w Discord Developer Portal włącz uprzywilejowane intencje Server Members Intent i Message Content Intent. Adres OAuth2 Redirect musi być identyczny z wartością REDIRECT_URI.

Instalacja krok po kroku

1

Przygotuj środowisko

Zainstaluj Node.js 20.11 lub nowszy. Skopiuj plik .env.example jako .env.

copy .env.example .env
2

Uzupełnij sekrety

W pliku .env podaj token bota, Client ID, Client Secret, długi losowy Session Secret oraz adres dashboardu i callbacku.

BOT_TOKEN=... CLIENT_ID=... CLIENT_SECRET=... SESSION_SECRET=minimum-32-losowe-znaki DASHBOARD_URL=https://twoja-domena.example REDIRECT_URI=https://twoja-domena.example/callback
3

Zainstaluj i sprawdź

Test obejmuje kod, konfigurację, lokalną bazę i prawdziwe uruchomienie serwera WWW.

npm install npm test
4

Wgraj 38 komend slash

Po każdej zmianie listy komend wykonaj wdrożenie ponownie.

npm run deploy
5

Uruchom

Bot i dashboard wystartują razem. Panel będzie dostępny pod adresem /dashboard.html.

npm start

Co jest połączone z dashboardem

Ochrona wiadomości

AntiSpam, AntiScam, listy domen, OCR obrazów i ignorowane kanały lub role.

Ochrona serwera

AntiRaid, lockdown, AntiAlt, Channel Guard i punkty ryzyka.

Obsługa użytkowników

Weryfikacja, tickety, Reaction Roles, odwołania i panele wysyłane na Discord.

Administracja

Role personelu, logi, warny, mute, kick, ban, backupy i Emergency Mode.

Kontrola po uruchomieniu

  • /ping — endpoint powinien zwrócić stan usługi.
  • /status — sprawdź moduły na Discordzie.
  • /dashboard — pobierz link do panelu.
  • /setup — przygotuj podstawowe kanały i role na serwerze.
  • PostgreSQL jest opcjonalny. Bez DATABASE_URL dane trafiają do lokalnego katalogu data/.
